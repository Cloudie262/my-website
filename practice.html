About Notepad

Notepad is a basic text editing program and it is mostly commomly used to view or edit text files. A text file is a file type typically defined by the [.txtfile] name extension.


How do i change the font style and size?


Changes to the font style and size effect all the text in the document.

Click the format menu, and then click Font.

Make your selections in the font, font styles and size boxes.

An example of how your font will look appears under sample.

When you are finished making font selections, click OK.
